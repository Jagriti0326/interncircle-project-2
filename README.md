# Project 02: Number Guessing Game & Word Counter

## Project Description
This project is a beginner-friendly Python command-line application developed for InternCircle Project 02. It combines a number guessing game with a word counting tool.

## Features

### Number Guessing Game
- Guess a randomly selected number between 1 and 100.
- Receive hints when a guess is too high or too low.
- Play with a limited number of attempts.
- Earn a score for winning.
- Track the best score during the session.

### Word Counter
- Read text from a file.
- Calculate the total number of words.
- Count unique words.
- Display the 10 most common words.

### General Features
- Menu-driven interface.
- Option to quit the program.
- File-reading functionality.

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal in the project folder.
5. Run:

   `python main.py`

6. Select an option from the menu.

## Files
- `main.py` — Contains the Number Guessing Game and Word Counter.
- `sample.txt` — Sample text file used to test word counting.
